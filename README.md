# Noise Radar

Mobile-friendly high-frequency chirp detector / signal-strength hunter.

## GitHub Pages setup
1. Put `index.html`, `style.css`, and `app.js` in the root of your repository.
2. Commit/push the files.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`, then **Save**.
6. Open the HTTPS GitHub Pages URL GitHub gives you.
7. Tap **START LISTENING** and allow microphone access.

## How to hunt the sound
Leave it in AUTO until the mystery chirp occurs. When it catches the tone, tap **LOCK TARGET**. Walk around with the phone. The radar return moves toward the center as the locked tone gets stronger.

Important: a single phone microphone cannot determine true direction. The marker's angle is decorative/stable; distance from the center is based on measured signal strength. Phone microphones also vary substantially at very high frequencies.
